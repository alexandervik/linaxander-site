# Линаксандер · сайт

Страница романа. Оформление, скрипт и картинки раздаются с GitHub Pages,
разметка вставлена блоком кода на странице Squarespace.

| файл | что это |
|---|---|
| `index.html` | вся страница целиком — для проверки по адресу GitHub Pages |
| `styles.css` | оформление + правила, скрывающие меню и футер Squarespace |
| `app.js` | дождь, карта с городами, появление блоков, форма |
| `code-block.html` | разметка — её содержимое вставляется в Code Block на странице |
| `assets/` | знак, рельефная карта Европы, четыре города, двор, окно |

## Правки

Меняем файл → коммит → через несколько минут страница обновится.
Если изменения не видны, добавьте версию в ссылку: `styles.css?v=2`.
